Install the Chrome extension

Install the Chrome extension free · open source

  1. Download the extension and unzip it.
  2. Open chrome://extensions in Chrome.
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select the unzipped folder.

Distributed through GitHub Releases. Chrome shows a Developer mode notice for extensions installed this way — the full source is public.

Save your first post

  1. Keep Eagle open, then open a post in Chrome.
  2. Click the extension icon → Save to Eagle.
