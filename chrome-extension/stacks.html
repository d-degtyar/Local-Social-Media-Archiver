Stacks in Eagle

One tile per post. Carousels stay together, and the library stays easy to browse.

→ →

  1. Turn on stacks

    In the extension popup, tick Stack posts in Eagle. From now on, every post you save to Eagle with more than one file goes into its own folder under Social Stacks, and its first file gets the tag Main Cover. A single image gets the tag too, without a folder.

  2. Create the “Stacks” smart folder once

    In Eagle, click + next to Smart Folders in the sidebar and choose New Smart Folder. Name it Stacks and set one rule:

    TagsAnyMain Cover

    Then click Create. Eagle cannot create smart folders from an extension, so this one step is yours.

  3. Browse posts, open a stack

    Open Stacks: one tile per post. Select a cover; in the right-hand panel, under Folders, click the post's folder to see every slide. Use ← and → to flip through them.

Good to know

  • Search works in Stacks. A cover carries the post's title, caption and tags, so searching inside Stacks finds posts, not loose slides. Searching in All still finds every file.
  • Make more feeds. Add a second rule, Tags · Any · instagram, and set the top line to all of the following are true for a feed of Instagram posts only.
  • New saves only. Items saved before you turned stacks on keep their place.
  • Change the cover by moving the Main Cover tag to another file in the post's folder.
